# dotfiles

> Living that shell life

## Prerequisites

- macOS

## Installation

### Clone the Repository

```sh
git clone https://github.com/chrisbradleydev/dotfiles.git ~/.dotfiles
cd ~/.dotfiles
```

### Run the guided setup script

```sh
./macos
```
